# AtlasCore

AtlasCore is a modern Service Desk application built with Angular and ASP.NET Core.

AtlasCore es una plataforma web para administrar incidencias y solicitudes de soporte técnico dentro de una organización.

Permite registrar, asignar, dar seguimiento y cerrar tickets, manteniendo un historial completo de todas las acciones realizadas.
## Tech Stack

- Angular
- ASP.NET Core
- SQL Server
- Entity Framework Core
- JWT Authentication
